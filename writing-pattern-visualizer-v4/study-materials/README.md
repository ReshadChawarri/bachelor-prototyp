Study Text Placeholders
=======================

`text-x.txt` and `text-y.txt` are placeholder master copies for Study Mode v1.0.

Replace their contents with the final study materials before running the user study. Keep the filenames unchanged so the application logic can continue to load Text X and Text Y without code changes.

Do not edit these files during participant sessions. Each study task loads a fresh copy into the editor and saves participant edits separately under the ignored backend `study-data/` directory.
